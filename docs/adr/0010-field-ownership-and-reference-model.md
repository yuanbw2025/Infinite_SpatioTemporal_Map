# ADR 0010：字段唯一所有权与 ID 引用模型

状态：已接受
日期：2026-07-16

## 背景

即使所有功能读取同一个发布包，重复字段仍可能形成内部多份真相。例如实体名和地点名、段落 ID 和来源中的段落 ID、卷名和段落中的卷名都可能分别被修改。

## 决策

1. 每个规范字段只有一个领域所有者，其他记录通过品牌 ID 引用。
2. Entity 拥有规范显示名；PlaceIdentity 拥有地点身份和历史名称，不重复规范名。
3. Passage.id 是唯一段落身份，来源定位不重复 passageId。
4. Volume 拥有卷名；Passage 只引用 volumeId，Edition 与 Work 通过父链推导。
5. Work.coverage 拥有作品地域覆盖，不保留语义重复的 describedRegion。
6. 文本证据使用 EvidenceSpan；外部 GIS/馆藏等使用 SourceRef。
7. 查询投影允许临时携带显示字段，但不可写、可重建、必须引用规范 ID 和数据版本。
8. 新字段必须通过所有权、重复性、来源、审核、消费者和迁移评审。

## 后果

- 当前重复字段按迁移路线从契约中移除；
- 页面不再依赖冗余 label 字段作为事实；
- 发布校验增加引用完整性和禁止嵌套对象副本规则；
- 字段消费者矩阵成为契约评审材料；
- 详细蓝图见 `docs/data-feature-blueprint.md`。
