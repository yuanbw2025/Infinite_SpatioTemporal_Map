# ADR 0011：统一命名、字段所有权与空值语义

- 状态：accepted
- 日期：2026-07-16

## 背景

0.3 原型在 TypeScript、JSON Schema、Python 和 UI 中分别手写字段与枚举，出现 ID 类型退化、重复归属字段、可选状态和空值语义不一致。继续按页面补字段会形成多个事实源。

## 决策

采用 `field-dictionary.md` 和 `engineering-rules.md` 的统一规则：JSON 线协议使用 camelCase，枚举使用小写 snake_case；Python 只在边界转换；主键固定 `id`，引用使用品牌 `<concept>Id`；集合不为 null；未知状态显式建模；每个事实字段只有一个所有者；可推导值和显示值不进入规范事实。

0.4 契约按字段字典收敛，所有破坏性字段变化由迁移器完成。JSON Schema 是字段和空值语义的唯一可执行来源。

## 后果

- 新功能先复用规范事实和 Assertion，而不能创建页面私有字段。
- 0.3 数据需要一次显式迁移，读取端不提供永久双字段兼容。
- 代码评审和自动检查可以识别命名、ID、null 与重复字段问题。
