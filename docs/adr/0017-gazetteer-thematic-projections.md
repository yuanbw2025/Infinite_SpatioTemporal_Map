# ADR 0017：地方社会与文博使用统一事实的专题投影

- 状态：Accepted
- 日期：2026-07-20

## 背景

简单按实体类型列卡片无法表达地方社会和文博研究问题；为每个页面建立专用对象又会复制人物、地点、关系和证据。

## 决策

- 地方社会与文博只组合 `Entity/Assertion/Occurrence/Evidence`；
- 方志高频但现有词表缺失的关系进入版本化核心谓词，不进入页面字段；
- application 统一生成 `ThematicRecord` 和专题计数；
- 页面只负责筛选、展示和 ID 导航；
- 不在发布包新增社会或文博并行集合。

## 后果

同一条任官、物产、馆藏或铭文事实能同时出现在实体档案、图谱、时间线、地图、检索和专题视图。后续增加专题只需扩展受控谓词或投影规则，不需要新内核。
