# ADR 0014：版本化核心关系谓词

- 状态：accepted
- 日期：2026-07-20

## 背景

`Assertion.predicate` 原为任意非空字符串。随着人物家族、师承、任官、文博和史源功能增加，不同导入器或页面可能为同一关系使用不同名称，或者把同一名称同时解释为实体关系和文字属性。这会破坏单一事实源，并使图谱、时间线和研究规则无法可靠组合。

## 决策

核心谓词成为发布契约的版本化枚举，并由 contracts 包提供唯一元数据注册表。每个谓词规定机器 ID、中文标签、分类、值类型、方向、反向谓词和适用实体类型。

Schema 负责拒绝未知 ID；Python 语义校验器负责值类型、主体类型和对象类型；application 只通过注册表取得显示标签和关系行为。反向关系在查询时推导，不为显示方便复制无独立证据的 Assertion。

新增或改变谓词语义属于契约变更。0.4 数据通过显式迁移进入 0.5；未知旧谓词必须由维护者提供映射，迁移器不得猜测。

## 后果

- 地方社会、文博、图谱、时间线和研究规则共享同一关系语义。
- 正式发布不能携带页面私有或拼写漂移的谓词。
- 扩充核心词表需要契约升级与迁移，但不会要求增加页面私有字段。
- 尚未能结构化的文字属性可暂用 `descriptive.note`，但仍需证据和审核。
