# ADR 0007：不可变发布物与完整数据血缘

状态：已接受
日期：2026-07-16

## 背景

地方志原件、OCR、转录、机器候选、人工判断和公开知识具有不同可信度与权利边界。直接覆盖 JSON 会破坏审计和回滚。

## 决策

数据按 Raw、Staging、Candidate、Decision、Canonical、Publication 六层保存。原件和决策追加式记录；Publication 是带版本、清单和校验值的不可变快照。

发布在临时目录完成合并、碰撞检查、契约与语义校验，再以原子操作形成新版本。公众应用只读指定版本；回滚只切换版本，不修改旧发布物。

## 后果

- 编辑 UI 不能直接写生产发布物；
- `promote` 等命令不得覆盖已有分片；
- 每条发布记录必须能追溯到决策和来源；
- 数据版本与应用版本解耦，但契约版本必须兼容。
