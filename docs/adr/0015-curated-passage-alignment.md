# ADR 0015：人工版本段落对齐进入统一发布契约

- 状态：accepted
- 日期：2026-07-20

## 背景

自动标签和次序配对可以辅助阅读，但无法可靠处理一对多、拆段、合段、重排和部分重合。若人工结果只保存在页面状态或独立旁路文件中，版本对读会形成第二套正文关系，且无法与发布版本、审核责任和迁移绑定。

## 决策

在 Text 模块增加 `PassageAlignment`，作为 `KnowledgePublication` 的正式顶层集合。记录以工作为范围，由多个“版本 + 段落 ID 集合”成员组成，并保存关系类型、审核状态、审核人、时间、说明和修订号。

对齐生产遵循建议批次 → 追加式人工决策 → 管线物化 → 新发布包的既有模式。建议和决策是生产材料，只有通过语义校验的已复核记录进入公众发布物。

版本对读用例优先消费人工记录；未被人工记录覆盖的段落仍可使用自动暂配。页面不直接读取决策文件，也不修改规范正文。

## 后果

- 支持一对一、一对多和多对多版本关系。
- 人工结果与发布包校验和绑定，可审计且不会漂移。
- 对齐不合并 Passage，也不消除异文。
- 0.5 发布包通过显式迁移增加空集合后进入 0.6。
