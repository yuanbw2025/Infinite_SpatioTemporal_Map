# ADR 0004：MapLibre GIS 引擎与可替换底图

## 状态

已采纳。

## 背景

无限时空图必须同时承载历史点位、行政区域、不连续辖区、人物行迹、时代播放和当前视野查询。自制坐标画布无法可靠处理投影、缩放、聚合、瓦片和大数据量，也会迫使后续功能建立第二套地图架构。

## 决定

- 公众站使用 MapLibre GL JS 作为浏览器 GIS 渲染引擎。
- 领域层只定义地点身份、历史几何和时空经历，不依赖 MapLibre 类型。
- Web 适配组件把 `MapObservation` 转成 GeoJSON Source；点、区域、路线和选中态作为独立图层。
- 历史区域同时支持 `Polygon` 和 `MultiPolygon`；发布管线校验坐标范围、环长度和闭合性。
- 底图样式由 `VITE_MAP_STYLE_URL` 配置，默认公共样式失效时降级为本地空白样式。
- 当前静态适配器按时间、对象类型和视野分页；将来可换成空间数据库、矢量瓦片或 PMTiles，页面用例和领域契约不变。

## 结果

地图具备平移缩放、比例尺、点位聚合、历史区域、人物行迹、图层开关、选中聚焦、时间播放和当前视野检索。正式历史数据接入后，这些能力无需重写即可启用；海量数据阶段只替换数据和瓦片适配器。
