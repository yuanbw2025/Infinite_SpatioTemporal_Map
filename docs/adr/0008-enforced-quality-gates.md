# ADR 0008：质量标准必须由自动门禁执行

状态：已接受
日期：2026-07-16

## 背景

类型检查和构建通过不能证明查询、数据管线和审核逻辑正确。只写质量原则而没有自动门禁会再次形成技术债务。

## 决策

合并与发布必须通过格式、静态分析、依赖边界、契约生成、测试覆盖、适配器合规、数据发布、安全和构建门禁。质量阈值定义在 `docs/quality-standard.md`，降低阈值必须有 ADR。

## 后果

- 在门禁补齐前冻结大规模功能扩张；
- 关键领域和发布代码要求更高覆盖率；
- CI 配置属于产品架构，不是可选运维附件；
- “本地能跑”不再等于“功能完成”。
