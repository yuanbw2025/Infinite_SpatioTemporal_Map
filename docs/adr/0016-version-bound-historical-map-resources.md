# ADR 0016：历史地图资源是版本绑定投影

- 状态：Accepted
- 日期：2026-07-20

## 背景

历代底图、扫描地图和疆域瓦片可能体积巨大，也可能由专门 GIS 服务提供。把它们全部塞入发布包会妨碍轻量分发；让地图页面直接接任意外部数据又会破坏单一事实源。

## 决策

- 地点身份、历史名称、有效时期和规范几何继续只属于发布包；
- 历史地图资源通过 `HistoricalMapResourcePort` 接入；
- 每个资源目录必须绑定发布包 `publicationId + contentChecksum`；
- 扫描地图引用发布包中的 `SourceRecord`，疆域 GeoJSON/瓦片视为规范几何的可重建投影；
- 时间适用性由 application 用例统一判断；
- UI 只管理可见性与透明度，不解释或修改历史事实。

## 后果

可以独立部署瓦片和 GIS 投影，同时保证它们不能脱离事实版本。未来改用矢量瓦片、数据库或远程目录时只增加适配器，不改变 Atlas 用例和其他功能。
