# 统一数据模型

## 核心对象

- `Work`：一部方志或文献。
- `Edition`：具体版本。
- `Passage`：稳定、可引用的文本段落。
- `Entity`：人物、地点、机构、事件、文物等规范实体。
- `Mention`：实体在某段原文中的一次出现。
- `Assertion`：带证据的知识主张，而不是无来源的“事实”。
- `PlaceIdentity`：跨时期稳定地点身份及历代名称、范围和隶属。

## 文本层

`Passage` 同时保存原文、简体转换和可选白话译文。影印页引用可以暂缺，但 `editionId`、`pageId` 和版面定位从一开始保留。

## 扩展规则

人物、地图、时间线和文博模块不得复制这些对象形成私有模型。模块需要的新属性优先表达为带来源的 `Assertion`；只有真正稳定、普遍且高频的属性才升级为核心字段。
