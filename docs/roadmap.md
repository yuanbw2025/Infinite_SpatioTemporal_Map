# 开发路线

## 阶段 -1：架构与质量加固（已完成）

已完成 `architecture-migration.md` 的 P0—P2：统一可执行契约、修复非原子发布、建立测试与 CI 门禁、恢复 domain/application/adapters 边界，并清零审核、地图和样式的大文件技术债。

## 阶段 0：原创根基（已完成）

已建立统一领域模型、数据契约、应用服务、模块注册、静态存储适配器、发布包校验、MapLibre GIS 边界和原创来源治理。

## 阶段 1：公众探索骨架（已完成，等待真实数据验证）

已接入方志博览、单层/并列阅读、影印缩放拖拽、泛实体百科、知识图谱、历史时间线、时空地图、人物行迹、文博浏览、研究线索、全库检索和数据说明。所有功能消费同一发布包与应用服务。

## 阶段 2：可信数据生产线（已完成软件能力）

已实现来源清单、权利与校验值门禁、多格式来源提取、OCR/人工转录接续、稳定无损分段、独立文本分层、原文精确提及器、统一候选、独立本地审核工作台、实体/历史地点对齐、引用重写、候选物化和正式发布门禁；虚构样本已从零重复生成同一发布物。下一步是用一部来源可靠的真实方志替换样本；影印本不是启动条件，但锚点必须保留。

## 阶段 3：首个时空证据闭环

完成一部方志的作品—版本—卷章—段落、人物/地点/时间/官职/事件、人工核验坐标、阅读器到地图、图谱到原文和时间线到百科的全链路。

## 阶段 4：历史地图与深度阅读

已实现历史地名按时代选择、年/月/日播放、五维组合检索、逐字异文与有界长文本保护的版本对读，0.6 正式人工篇章对齐及校勘闭环，IIIF Presentation 2/3 Canvas 与 Image API 瓦片深度查看、多页影印和版面区域联动，以及版本绑定的历代栅格地图/疆域 GeoJSON 资源体系。词面、语义和混合检索、版本绑定向量索引与查询向量端口也已完成；真实部署只需生成索引并连接向量服务。

## 阶段 5：地方社会与文博

已完成跨人物、图谱、时间线、研究和文博功能共享的核心关系谓词及显式迁移；0.7 已加入人口、户口、赋役、物产、贡物、风俗和事件类型，并完成家族、师承、任官、交往、迁徙、事件、民生七类地方社会专题，以及文物、遗址、馆藏、材料、工艺、纹样、铭文和流转的统一文博档案投影。真实数据到来后只需按受控字段接入和校定。

## 阶段 6：多方志互证与研究平台

0.8 已完成受控来源谱系、来源链浏览、可解释内置研究规则和可信只读规则端口。接入同地区历代方志及相邻地区资料后，可直接深化异文、史源、反常与争议审核，并继续建立可协作的编辑工作台。

## 阶段 7：全国方志时空博览

通过已建立的全文检索与空间查询端口接入规模化索引、空间数据库与矢量瓦片，在不复制领域模型的前提下形成跨地域、跨朝代、可持续协作和可追溯的公众历史探索平台。
