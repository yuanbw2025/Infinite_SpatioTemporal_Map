# 完成度与剩余工作

截至 2026-07-20，项目的软件底座已经达到“可以直接接入真实数据”的状态。

## 已完成

- 一个 JSON Schema 权威契约及 TypeScript/Python 双端执行校验；
- 单一不可变发布包、内容校验和、原子发布和版本绑定；
- `domain / ports / application / adapters / apps` 固定依赖方向；
- 书库、阅读器、带逐字异文和相似度的版本对读、IIIF/直接图像多页影印与区域联动、实体档案、检索、地图、人物行迹、年/月/日时间线、图谱、文博和研究线索；
- 可替换的全文检索、空间查询和影像解析端口，默认仍共享同一发布包；
- 来源登记、文件校验、提取、转录接续、无损分段、文本分层、候选提取、人工审核、实体/地点对齐和发布门禁；
- 虚构数据的可重复端到端测试；
- 架构、格式、类型、覆盖率、管线、数据、构建体积和仓库卫生门禁；
- 原架构债务清零，不再存在 `packages/core` 或千行业务适配器。

## 真实数据到来后需要做的工作

这些工作是内容建设和基于真实资料的校定，不需要另起技术架构：

1. 确认首部方志文本的来源、权利和版本信息；
2. 导入原文并由领域人员审核分段、简繁层、句读和译文；
3. 审核人物、地点、关系、事件、年代与历史几何；
4. 用真实数据做可用性、性能和历史准确性验收；
5. 后续逐页补充影印图像、IIIF Canvas 及经人工校定的版面锚点。
