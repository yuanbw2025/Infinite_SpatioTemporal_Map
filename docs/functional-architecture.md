# 功能架构

## 公众探索面

### 方志博览

负责地区、时代、书目、版本和卷次的入口。它拥有导航语境，不拥有全文、人物或地图数据的副本。

### 方志精读

按稳定段落 ID 展示原文、简体和白话层，承载实体高亮、注释、出处与未来影印页联动。

### 无限时空

按空间范围、时间范围和对象类型查询观测；由 MapLibre 渲染可缩放底图、聚合点、历史区域（含不连续辖区）、人物行迹和地名标签。时间轴既可筛选范围，也可逐年或按步长播放；地图移动后按当前视野重新查询。点、面和路线都只消费统一 `MapObservation`，不建立地图专用知识库。

地图选中对象后聚焦其几何并进入实体档案，实体档案再通过证据返回方志原文。底图样式、未来瓦片服务和海量数据接口位于适配边界，替换它们不改变地点身份、历史几何或时空经历契约。

### 人物行迹

组织籍贯、任职、游历、交往、事件和关系。所有关系都是带时间与证据的 `Assertion`。

### 文博遗产

容纳文物、遗址、墓葬、馆藏、材料、工艺、纹样与铭文。它们仍是统一实体，通过证据和地点身份连接方志与现实收藏。

### 全库检索

统一检索作品、段落与实体，提供时代、地域、来源和实体类型筛选；搜索引擎可以替换，返回契约不变。

## 编辑生产面（后续）

数据导入、候选审核、实体合并、地点对齐、证据校验和发布属于编辑工作台。工作台与公众站共享契约和领域规则，但权限、界面和部署可独立；不得复制一套领域模型。

## 横切能力

- 来源与权利：记录每个版本和数据集的来源、持有机构、链接与权利说明。
- 审核状态：机器候选、已审核、已核验、争议和拒绝始终可区分。
- 版本迁移：发布包声明契约版本，适配器拒绝不兼容数据。
- 可观测性：将来在应用服务边界记录查询耗时、缺失引用和数据版本。
- 国际化与文本：先服务中文史料，界面文案与史料文本层严格分离。
