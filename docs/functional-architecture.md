# 功能架构

## 公众探索面

### 方志博览

负责地区、时代、书目、版本和卷次的入口。它拥有导航语境，不拥有全文、人物或地图数据的副本。

### 方志精读

按稳定段落 ID 展示原文、简体和白话层，承载实体高亮、注释、出处与未来影印页联动。

### 版本对读

同一作品的两个版本通过统一 `Edition` 与 `Passage` 查询并列展示。版本对读由 application 用例按卷章与段落标签优先、同卷次序辅助配对，明确标识暂配和单侧段落，并以 Unicode 字符为单位显示增删异文与相似度。超长差异采用有界粗略比较，避免异常文本拖垮浏览器。

自动配对只生成只读投影，不篡改异文，也不写回领域数据，更不能冒充人工判断。将来加入人工校定的版本对齐记录时，应进入统一发布契约并由同一用例优先读取，不能在页面或独立文件中建立第二套正文关系。

### 无限时空

按空间范围、时间范围和对象类型查询观测；由 MapLibre 渲染可缩放底图、聚合点、历史区域（含不连续辖区）、人物行迹和地名标签。地点标签从 `HistoricalPlaceName.validDuring` 选择当前时代名称；时间轴既可筛选范围，也可按年、月或日逐步播放。地图移动后按当前视野重新查询。点、面和路线都只消费统一 `MapObservation`，不建立地图专用知识库。

地图选中对象后聚焦其几何并进入实体档案，实体档案再通过证据返回方志原文。底图样式、未来瓦片服务和海量数据接口位于适配边界，替换它们不改变地点身份、历史几何或时空经历契约。

### 人物行迹

组织籍贯、任职、游历、交往、事件和关系。所有关系都是带时间与证据的 `Assertion`。

### 知识图谱

从 `Assertion.subjectId/objectId` 生成可查询关系网，支持以任一百科实体为中心按深度展开。节点只引用统一实体，关系边保留审核状态、时间与证据；点击节点进入百科，点击出处进入阅读器。

### 历史时间线

把带时间的 `Assertion` 与 `SpatiotemporalOccurrence` 组织为实体轨道。宏观比较可以跨朝代，人物生平和文物流转可以使用月、日精度；界面同时显示原始纪年和公元换算。

### 文博遗产

容纳文物、遗址、墓葬、馆藏、材料、工艺、纹样与铭文。它们仍是统一实体，通过证据和地点身份连接方志与现实收藏。

### 全库检索

统一检索作品、段落与实体，提供时代、地域、来源、实体类型和审核状态组合筛选；筛选条件写入 URL，可分享和复现。搜索引擎可以替换，返回契约不变。

### 研究工具

在应用服务边界发现矛盾主张、争议记录、纪年次序冲突和待定位地点。研究工具只提出带证据的核验线索，不自动消除异文或宣布唯一结论。

## 编辑生产面

数据导入、候选审核、实体合并、地点对齐、证据校验和发布属于编辑生产面。当前独立的 `apps/curation` 工作台可以导入候选批次和发布包原文，逐条核对证据上下文、修正 payload、核定/争议/驳回、在本机保存进度并导出追加式决策；管线负责把决策物化为标准分片并执行正式发布门禁。

工作台与公众站共享候选、审核状态和证据契约，但构建、权限和部署独立；它不直接改发布包，也不复制一套领域模型。工作台现已包含独立的实体/地点对齐区：展示原记录、可能目标、匹配评分与理由，人工选择合并、新建或保持分立；管线统一完成异名保留、引用重写和冲突校验。

## 横切能力

- 来源与权利：记录每个版本和数据集的来源、持有机构、链接与权利说明。
- 审核状态：机器候选、已审核、已核验、争议和拒绝始终可区分。
- 版本迁移：发布包声明契约版本，适配器拒绝不兼容数据。
- 可观测性：将来在应用服务边界记录查询耗时、缺失引用和数据版本。
- 国际化与文本：先服务中文史料，界面文案与史料文本层严格分离。
